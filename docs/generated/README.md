## Generated documents

This directory is reserved for documents generated during agent tasks.

From this change onward, any new analysis or generated write-up produced by the agent should be placed here instead of mixed into the hand-written project docs.

## Layout

- `analyses/`
  - canonical generated write-ups that should be treated as the primary version
- `archive/`
  - exact copies of generated docs merged in from other cursor branches
  - kept for preservation and traceability instead of being deleted
